# LoL Remote

Controla el cliente de League of Legends desde el celular: crear sala, invitar, buscar y aceptar partida, banear y elegir campeón, skins, hechizos, runas, cambios de campeón o línea, marcador en vivo y más. No controla la partida en sí, solo el cliente.

## Descargar

**[Descargar LoL Remote (última versión)](https://github.com/Rasherx/lolremote/releases/latest/download/LoLRemote.zip)**

1. Descomprime el zip y abre `LoLRemote.exe` en la PC donde juegas.
   - Si Windows dice "Windows protegió su PC": **Más información → Ejecutar de todas formas**.
   - Si el firewall pregunta: **Permitir**.
2. En la ventana verás un PIN y una dirección.
3. En el celular (misma WiFi), abre esa dirección en Chrome, toca **Descargar app para Android** e instálala. Escribe el PIN una vez.

El programa de la PC se actualiza solo. Las instrucciones completas están en `LEEME.txt` dentro del zip.
